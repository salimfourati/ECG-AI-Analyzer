app module
==========

Ce module contient la logique principale de l’application Streamlit.
Il orchestre :

- le chargement des données ECG
- l’interaction utilisateur
- l’appel aux modules d’analyse
- l’affichage des résultats
- l’export des rapports

L’application constitue l’interface entre l’utilisateur et les modules de traitement.
